# GO PLACE 1.0 — инструкция для новичка

## Что это
Мобильный PWA-прототип: сайт, который можно установить на главный экран телефона.
В нём работают выбор города, поиск, категории, фильтры, сортировка, карточки и избранное.

**Важно:** карточки, названия, адреса, рейтинги и количество отзывов в `app.js` — демонстрационные данные. Это не проверенные рекомендации и не реальные рейтинги.

## 1. Как открыть проект на компьютере
1. Распакуйте архив `GO_PLACE_1_0.zip`.
2. Откройте папку `go_place_1_0`.
3. Для быстрой проверки можно открыть `index.html` двойным нажатием.
4. Для проверки установки PWA и офлайн-режима запустите локальный сервер. Если установлен Python, откройте терминал в папке проекта и выполните:
   `python -m http.server 8000`
5. Откройте `http://localhost:8000`.

## 2. Как бесплатно опубликовать в интернете через GitHub Pages
1. Создайте аккаунт на https://github.com/.
2. Создайте новый публичный репозиторий, например `go-place`.
3. Нажмите **Add file → Upload files**.
4. Загрузите содержимое папки проекта (файлы должны оказаться в корне репозитория).
5. Откройте **Settings → Pages**.
6. В разделе Build and deployment выберите **Deploy from a branch**.
7. Выберите ветку `main` и папку `/ (root)`, нажмите Save.
8. Подождите публикации. GitHub покажет адрес сайта в разделе Pages.

Бесплатный тариф и условия хостинга могут меняться; для публичного проекта проверьте актуальные лимиты GitHub Pages.

## 3. Как установить на Android
1. Откройте опубликованный HTTPS-адрес в Chrome.
2. Откройте меню браузера (три точки).
3. Выберите **Установить приложение** или **Добавить на главный экран**.
4. Подтвердите установку.

На iPhone откройте сайт в Safari → «Поделиться» → «На экран Домой».
PWA-функции и установка зависят от браузера и устройства.

## 4. Как проверить функции
- Нажмите на название города и переключите город.
- Введите слово в поиск.
- Выберите категорию.
- Измените сортировку и ценовой фильтр.
- Нажмите сердечко, затем вкладку «Избранное».
- Откройте карточку места кнопкой «Подробнее».
- После обновления страницы избранное и город должны сохраниться на этом устройстве.

## 5. Как изменить демонстрационные карточки
Откройте `app.js`. В начале файла найдите массив `data`.
Каждый объект — одна карточка. Поля:
- `id` — уникальный идентификатор;
- `city` — город;
- `name` — название;
- `cat` — категория: Еда, Отдых, Развлечения или Природа;
- `address` — адрес;
- `rating`, `reviews` — только проверенные показатели с известным источником;
- `price` — 1 (бюджетно), 2 (средняя цена), 3 (выше средней);
- `symbol`, `kind`, `desc` — оформление и описание.

Не публикуйте вымышленные оценки как настоящие. Для реальных данных сохраняйте источник и дату проверки, соблюдайте условия его использования и права на фотографии.

## 6. Подключение базы данных — следующий этап
Файл `supabase_schema.sql` содержит начальную структуру таблиц:
- cities — города;
- categories — категории;
- places — места;
- place_rating_snapshots — история проверок рейтинга;
- place_photos — фотографии и сведения о правах;
- favorites — избранное пользователей.

Чтобы подключить:
1. Создайте бесплатный проект на https://supabase.com/.
2. Откройте SQL Editor.
3. Вставьте `supabase_schema.sql` и выполните.
4. Перед подключением реальных аккаунтов проверьте RLS-политики.
5. В браузер можно помещать только публичный anon/publishable key с корректными RLS-политиками. Никогда не помещайте `service_role` или секретный ключ в `app.js`.

Сейчас прототип использует локальные демонстрационные данные и `localStorage`; Supabase ещё не подключён.

## 7. Ограничения нулевого бюджета
- Бесплатные тарифы имеют лимиты, могут менять условия и не гарантируют неограниченную работу.
- Домен, публикация в магазинах приложений, карты, SMS и некоторые API могут потребовать оплаты.
- На первом этапе используйте PWA, каталог небольшого размера и ссылки на внешние карты.
- Не собирайте лишние персональные данные. Перед публичным запуском подготовьте политику конфиденциальности и правила использования.

## Состав проекта
- `index.html` — структура экранов;
- `styles.css` — сине-белый дизайн;
- `app.js` — логика поиска, фильтров, избранного и демо-каталог;
- `manifest.webmanifest` — настройки PWA;
- `sw.js` — кеширование для офлайн-открытия;
- `icon.svg` — иконка;
- `supabase_schema.sql` — будущая схема базы данных.
